# M6-3 客戶端（裝置）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 裝置上的插件（`client` 模式，不連 CalDAV）在 `[[短ID|標籤]]` 後面顯示可操作的 chip，所有修改都寫到投影檔 frontmatter；以通知回饋 `_sync`；衝突用對話框處理；本機誤刪／改名投影檔立即還原；可新建任務。伺服器補上「新建」路徑。

**Architecture:** 客戶端只讀寫 vault：chip 狀態由 `metadataCache` 的 frontmatter 推導（純函式 `chipView`）；寫入一律 `processFrontMatter`，之後由 M6-2 的伺服器上行處理。客戶端守門用 S9 的 LiveSync 來源判斷，只處理本機動作。新建：客戶端建立沒有 `_etag` 的投影檔，伺服器看到後排入 0.5.0 的 `PendingCreate` 佇列。

**Tech Stack:** TypeScript、CodeMirror 6、vitest、spike 實例 + LiveSync 雙 vault e2e。

**Spec:** `docs/plans/2026-11-23-m6-server-projection-design.md`（§7.2、§8.3、§8.6、§8.8、D8、D9）；S1、S2、S9。

## Global Constraints

- `mode`: `"legacy" | "client" | "server"`，**預設 `legacy`**（=0.5.0 行為；既有安裝不受影響）。M6-1/M6-2 中 `mode !== "server"` 的判斷改為 `mode === "legacy"`。`client` 模式不建立 CalDAV session、不跑同步、不註冊 0.5.0 的 `cal:` 渲染。
- 客戶端只寫可寫欄位與 `_request`；不寫其他 `_` 欄位。
- chip 定位沿用 S1 規則（`formatting-link-start` → 第一個不含 `link-alias` 的 `hmd-internal-link` → `formatting-link-end`；嵌入不加；`Decoration.widget({ side: 1 })`；`ignoreEvent() → true`；mousedown `preventDefault`）。來源路徑用 editor 自己的檔案（`editorInfoField`），不用 `getActiveFile()`。
- `_hash` 改為同步計算（chip 要在渲染時比對），演算法：可寫欄位依 `WRITABLE_KEYS` 正規化 JSON → FNV-1a 64-bit（兩個 32-bit）→ 16 hex。伺服器與客戶端共用 `writableHash`。
- 本機還原只在 S9 判斷為本機動作（`isFileProcessing || recentlyTouched` 皆 false）時做；特徵檢查不通過 → 不做本機還原。
- e2e 只用 spike 實例、臨時 vault、`m6-spike` 資料庫、Radicale 臨時集合；結束清理附輸出。每個 Task 結束 `npm test`、`npm run build` 通過。

## Review Focus

1. **裝置新建的檔案在伺服器處理前**：不得被對帳標成 `_deleted`、不得被 guard 當成重複 → Task 1 `unsent-create-not-deleted`。
2. **LiveSync 帶來的刪除／改名（伺服器搬移的改名）**：客戶端不得還原 → Task 5 `remote-delete-not-restored`（e2e）。
3. **chip 點擊與連結點擊**：互不干擾（S1 已驗證機制）→ Task 4 e2e。
4. **重複任務、已刪除任務的 chip**：勾選框停用，不寫入 → Task 3 `recurring-checkbox-disabled`、`deleted-readonly`。
5. **衝突對話框選「伺服器的」**：寫 `_request: dismiss-conflict`，不改可寫欄位 → Task 5 測。
